# 视觉记录：深海手记

首页采用深海蓝、青绿色和纸白色。深色只用于封面，正文沿用 GitHub 的原生阅读界面。海流般的等高线暗示探索的过程，留白让标题和阅读入口保持清楚。

封面以大字号的 UTDR 建立识别，配小字号的等宽目录文字和一行衬线字体。精细控制基线、边距与线条密度，让视觉节奏来自清晰的对齐关系。图形本身保留足够空间，缩小到 README 宽度后仍能辨认。

内容采用编号章节、简短说明与少量表格。每张图承担明确任务：封面表达主题，像素图连接数字与视觉，泛化图帮助解释一次真实的学习讨论。对数字标签、文字间距和图例反复核对，避免装饰削弱内容。

成长通过原始回答、纠错和成果链接表现。精心维护的细节包括来源、状态、日期和可复查的运行方式；未完成的实验保留真实状态。版面可以随记录增多自然延伸，成果区始终放在首页最后。

## 素材与许可

- 封面由本仓库的 `scripts/build_visuals.py` 绘制，采用原创几何线条。
- 泛化图的数值为学习例题，明确标注为教学示例。
- Bricolage Grotesque、Crimson Pro、DM Mono 的字体与 OFL 许可保存在 `assets/fonts/`。
- 图中中文可使用本机字体渲染；系统字体文件不随仓库分发。
