## 怎么更新

```powershell
python scripts/new_entry.py --topic "今天的问题"
```

填写新生成的文件，将 `status` 从 `draft` 改为 `recorded` 后，执行：

```powershell
python scripts/new_entry.py --refresh
```

脚本会同步更新本页索引和首页最近三篇记录。具体用法见[维护说明](../docs/maintenance.md)。
