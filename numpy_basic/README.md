今天的目标：能解释 `shape`，取出一个像素，并通过切片裁剪图片。

## 1. 图片可以看成一张数字表（15 分钟）

先看这张 3 行、4 列的表：

```python
import numpy as np

gray = np.array([
    [0,   64, 128, 255],
    [32,  96, 160, 224],
    [255, 192, 128,   0],
], dtype=np.uint8)
```

它就是一张很小的灰度图片：每个数字对应一个像素。在本课使用的 8 位灰度表示中，0 是黑色，255 是白色，中间的值表示不同灰度，数值越大显示越亮。

`np.array(...)` 把嵌套列表转换成 NumPy 数组。`np.uint8` 表示使用 8 位无符号整数存储，每个元素可以取 0～255。

这里使用的是一种常见图片表示；其他任务中也可能使用浮点数等数据类型。

```python
print(gray.shape)  # (3, 4)：3 行、4 列，也就是高 3、宽 4
print(gray.ndim)   # 2：有行和列这两个轴
print(gray.dtype)  # uint8：每个数怎样存储
```

注意：灰度数组有两个轴，不代表画面是三维空间中的物体。

## 2. 用索引找到一个像素（10 分钟）

NumPy 的索引从 0 开始。在这张图里，行从上往下增加，列从左往右增加。

```python
print(gray[1, 2])  # 160：第 2 行、第 3 列
```

顺序是 `gray[行, 列]`，对应 `gray[y, x]`。

先在上面的表里用手找到这个位置，再运行代码核对。

## 3. 裁剪图片就是截取一部分数组（10 分钟）

```python
crop = gray[0:2, 1:4].copy()
```

- `0:2` 选择索引为 0、1 的行。
- `1:4` 选择索引为 1、2、3 的列。
- 冒号左边包含，右边不包含。
- 结果有 2 行、3 列，所以 `crop.shape` 是 `(2, 3)`。
- NumPy 的基本切片通常共享原数组的数据。这里的 `.copy()` 生成独立副本。

裁剪后的内容是：

```text
[[ 64 128 255]
 [ 96 160 224]]
```

## 4. 彩色图片多了颜色通道（10 分钟）

本课使用 RGB 表示，每个像素由 `[红, 绿, 蓝]` 三个数构成：

```python
[255, 0, 0]  # 红色像素
[0, 255, 0]  # 绿色像素
[0, 0, 255]  # 蓝色像素
```

对本课的 RGB 数组，`shape` 的顺序是 `(高, 宽, 通道数)`。例如 `(2, 3, 3)` 表示高 2、宽 3、每个像素有 3 个颜色通道，总共有 6 个像素。

因此，图片数组的维度数与像素数量是不同的概念。

示例会把图片保存到 `numpy_basic/outputs/lesson01/`：

| 文件 | 用途 |
| --- | --- |
| `overview.png` | 带索引和数值的对照图，先打开这个 |
| `gray.png` | 3×4 像素的原始灰度 PNG |
| `rgb.png` | 2×3 像素的原始 RGB PNG |
| `crop.png` | 3×2 像素的裁剪结果，文件尺寸按宽×高描述 |
| `gray_enlarged.png` | 最近邻放大后的灰度图，便于看清像素块 |

代码演示了“数组 → 保存为 PNG → 从 PNG 读取数组 → 裁剪 → 保存”的过程，不需要准备照片。

尺寸顺序尤其容易弄反：

| 操作 | 顺序 |
| --- | --- |
| NumPy 灰度数组的 `shape` | `(高, 宽)` |
| 本课 NumPy RGB 数组的 `shape` | `(高, 宽, 通道数)` |
| Pillow 图片的 `size`、`resize` 参数 | `(宽, 高)` |

放大图片会增加像素数量，但最近邻放大只是复制已有像素信息，不会恢复原本没有记录的细节。
